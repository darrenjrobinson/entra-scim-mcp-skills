# Decision record: field-by-field guide

Contract: `entra-lifecycle-policy/policy/decision-record.schema.json`. Shape to copy: `entra-lifecycle-policy/policy/decision-record.example.json`. Every field below is required unless marked optional.

## Enums (spell exactly)

| enum | values |
|---|---|
| Decision | `allow` `allow_with_approval` `deny` `require_manual_review` |
| Outcome | `completed` `blocked` `awaiting_approval` `partial_failure` `not_executed` `rehearsal` |
| RiskLevel | `low` `medium` `high` |
| CheckResult | `pass` `fail` `warn` `needs_approval` `manual_review` `skipped` |
| ExecutedAction.status | `ok` `error` `dryRun` |
| ExecutedAction.phase | `resolve` `read` `execute` `verify` |
| PlannedAction.status | `planned` `executed` `skipped` `not_attempted` |
| host | `mcpjam` `claude-code` `other` |
| clockSource | `resourceMeta` `none` |
| event | `joiner` `mover` `leaver` `entitlement-evaluation` |
| skill | `entitlement-guardrail` `identity-change-auditor` `joiner-orchestrator` `mover-orchestrator` `leaver-orchestrator` |

ReasonCode: `policy_unavailable` `unknown_source` `missing_required_attribute` `csa_missing` `csa_condition_failed` `group_not_in_catalog` `group_not_found_in_tenant` `duplicate_group_display_name` `not_allowed_at_joiner` `privileged_not_allowed_at_joiner` `breakglass_only` `exceeds_profile_risk` `sod_conflict` `approval_required` `approval_missing` `approval_invalid` `approval_scope_mismatch` `operator_confirmation_missing` `ambiguous_identity` `already_provisioned` `unresolved_manager` `source_conflict` `cost_budget_exceeded` `partial_failure` `verification_failed` `dry_run_active` `delete_blocked_legal_hold`

## Header

| field | how to fill |
|---|---|
| `recordVersion` | `"1.0"` (from `auditRequirements.recordVersion`) |
| `correlationId` | the run's id, format `elg-<sourceRecordId>-<6 lowercase alphanumerics>`; generated by the calling skill at the start of the run and reused unchanged |
| `supersedes` | previous run's correlationId when this is a re-run after a block, else `null` |
| `skill`, `skillVersion` | the calling skill and its `metadata.version` |
| `policyId`, `policyVersion` | from the loaded policy |
| `event` | the run type |
| `host` | `mcpjam` if you have `loadSkill`/`readSkillFile` tools, `claude-code` if you have Read/Skill tools, else `other` |
| `dryRun` | `true` if any tool result contained `"dryRun": true` |
| `startedAt` / `completedAt` | earliest / latest `meta.created` or `meta.lastModified` seen in tool results this run, else `null` |
| `clockSource` | `resourceMeta` when timestamps came from tool results, `none` when both are null |
| `source` | `{system: <sourceSystem>, recordId: <sourceRecordId>}` |
| `target` | `{userName, id (resolved or created this run, else null), displayName}` |
| `decision`, `riskLevel` | from the check table aggregate row |
| `outcome` | per the classification table in SKILL.md |

## policyChecks[]

One per check-table row, in the same order.

| field | how to fill |
|---|---|
| `id` | `CHK-01`, `CHK-02`, ... exactly as printed in the table |
| `rule` | dotted policy path: `requiredJoinerAttributes.customSecurityAttributes[REQ-CSA-03]`, `sodRules[SOD-FIN-001]`, `groupCatalog[SG-Finance-Treasury-Payments].requiresCsa`, `evaluation.decisionPrecedence` for the aggregate row |
| `subject` (optional) | the group or attribute the row is about |
| `input` (optional) | the normalised value evaluated, or `(absent)` |
| `evidence` | `call #3: list_groups displayName eq ... -> 1 match id ...`, or `source record`, or `policy` |
| `result` | CheckResult |
| `reasonCode` | required when result is `fail`, `needs_approval` or `manual_review` |

## approvals[]

Every ref that appeared in the record or an operator message.

`{ref, scope, approver, sourceRecordId, grantedAt|null, valid, used, invalidReason?}`. `valid` = passed pattern, requiredFields, sourceRecordId match and scope match. `used` = an executed write depended on it. An invalid ref is still listed, with `valid: false` and `invalidReason`.

## plannedActions[]

The preview table rows. `seq` from 1 in execution order. `tool` from the 18 names. `target` = userName, group displayName or `<new user id>`. `argsSummary` = key arguments with ids as resolved, password always `<generated, not shown>`. `purpose` short. `policyBasis[]` = dotted paths. `status`: `executed` if a matching executedAction has status ok, `skipped` if in skippedActions, else `not_attempted` (`planned` is only for a record emitted before execution, i.e. `awaiting_approval`).

## executedActions[]

Every tool call, reads included, in the order made.

| field | how to fill |
|---|---|
| `call` (optional but recommended) | sequential number 1..n, the number cited in evidence |
| `seq` | the plannedActions seq this call fulfilled; `0` for resolve/read/verify calls |
| `phase` | `resolve` (id lookups), `read` (current state), `execute` (writes), `verify` (post-state reads) |
| `tool` | the tool name |
| `status` | `ok`, `error` (result had `isError`), `dryRun` (result had `dryRun: true`) |
| `at` | `meta.created` / `meta.lastModified` from that result, else `null` |
| `resultSummary` | ids, counts, `patchCalls`, `noChanges`, `totalResults`; never the full payload |
| `error` (when status error) | the structured error object verbatim: `{error, status?, scimType?, detail?, ...}` |

## skippedActions[]

`{seq|null, tool, target?, group?, reason, reasonCode}`. `seq` is the planned seq it replaces, or `null` for a requested group that never made it into the plan (denied by the guardrail).

## verificationFindings

`proved[]`: `{check, tool, expected, observed, result}` per verification read, e.g. `{check: "memberships equal planned set", tool: "list_groups", expected: "[All Employees, SG-Finance-Users, ...]", observed: "[...]", result: "pass"}`.

`notVerifiable[]`: strings. Standard list for this MCP surface: `sign-in sessions and tokens`, `licence assignment`, `mailbox provisioning`, `nested or transitive group access`, `application role assignments`, `PIM eligibility`, `whether a Lifecycle Workflow was triggered by employeeLeaveDateTime`. Include the ones relevant to the run.

## residualRisk[]

`{id: RR-01.., description, severity, owner, dueBy|null}`. Owners are the policy's `groupCatalog[].owner` values, `hr-data`, `identity-ops`, `legal`, or the operator.

## toolCalls

`{count, budget, byTool}`. `count` = executedActions length. `budget` = `costThresholds.maxToolCallsPerRun.<skill>`. `byTool` = `{"list_users": 3, "list_groups": 2, ...}` with no zero entries. Add a `warn` check row when `count` ≥ `warnAtPercent` of `budget`.

## nextSteps[] and summary

`nextSteps`: concrete, one per line, addressed to a human. `summary`: five sentences per the template in SKILL.md, under `summaryMaxWords`.

## details (optional)

Free-form per skill: guardrail `groupResults[]` (`{displayName, id|null, result, reasonCodes[], ruleIds[], approvalScopeNeeded|null}`); mover `before` / `after` objects; leaver `mode`, `retained[]`, `residual[]`.

## Evidence-writing rules

- Cite the call number: `call #4: list_users userName eq patti.fernandez@contoso.local -> 1 result, active=true, id 6f1c...`.
- Quote counts and ids, not payloads.
- For a policy-only check: `policy: groupCatalog[SG-Legal-Hold].allowedAtJoiner=false`.
- For a source check: `source record: customSecurityAttributes.Compliance.DataClassification absent`.
- Never write "verified" without naming the read that verified it.
